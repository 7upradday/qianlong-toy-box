# 乾隆的玩具盒

## 打开方式

互动式清宫珍玩 3D 网站。在线版本通过 GitHub Pages 发布；本地开发时在本目录启动静态服务器后打开 `index.html`。

## 已实现

- 萌版乾隆三段式开场对话。
- 开场结束后自动抽取主题、布局和 10 件物件。
- 点击“换一局”，完成关柜、换局、重新开柜。
- 原版瑾瑜匣 3D 外观，可旋转、缩放并自动转动。
- 开匣运镜与实体三维百宝格，匣内展示真实 GLB 模型。
- 轻点器物进入详情，支持自由旋转与缩放。
- 从 35 件本地三维珍玩宝库中替换当前器物。
- 首屏只加载匣体；开匣后才按需加载当前 10 件模型，宝库使用轻量图片预览。
- 开场首屏不启动 WebGL；两套三维运行时分别在两段对白阅读期间后台准备。
- 35 件藏品模型已在保留外观的前提下压缩，合计体积由约 358 MB 降至约 42 MB。
- 外观匣体由约 5 MB 降至约 1.2 MB，木纹图由 4096² 降至 1024²。
- Lighthouse 移动端首屏测试：性能 98，FCP 1.1 秒，LCP 1.7 秒，TBT 0 毫秒。
- 长按隔间后拖到另一格，交换物件和隔间尺寸。
- localStorage 保存最近一次选品。
- Canvas 生成“寡人钦点 · 十件皇家选品”纪念卡。
- 纯本地资源，无外部 CDN、图片、字体或网络请求。

## 发布文件

- `index.html`：唯一入口文件。
- `styles.css`、`cabinet-physical.css`：界面与三维匣体样式。
- `app.js`、`cabinet-physical.js`、`collection-3d.js`：交互、三维场景与藏品数据。
- `assets/models/collection/`：35 件藏品模型。
- `assets/vendor/`：本地三维运行依赖，无外部 CDN。
- `vercel.json`：为模型、图片和本地三维依赖设置长期 CDN 缓存。
