# 乾隆的玩具盒 - 首版 Build

## 打开方式

推荐在本文件夹运行一个本地静态服务器后打开 `index.html`。上传小红书小工具时，将本文件夹中的 HTML、CSS、JS 与 `assets` 整体打包，保持相对路径不变。

## 首版已实现

- 萌版乾隆三段式开场对话。
- 开场结束后自动抽取主题、布局和 10 件物件。
- 点击“换一局”，完成关柜、换局、重新开柜。
- 轻点隔间查看文物卡。
- 从 35 件本地物件宝库中替换当前物件。
- 长按隔间后拖到另一格，交换物件和隔间尺寸。
- localStorage 保存最近一次选品。
- Canvas 生成“寡人钦点 · 十件皇家选品”纪念卡。
- 纯本地资源，无外部 CDN、图片、字体或网络请求。

## 当前素材状态

- 瑾瑜匣核心物件 10 件。
- 粉色莲花器候选 16 件。
- 奇怪瓷器候选 9 件。
- 粉彩荷花吸杯与各种釉彩大瓶已经换成由真实馆藏照片整理的白底图。
- 其余粉色/奇怪瓷器当前仍是用户提供插画的临时原型图，只用于页面选品测试，不用于 3D 建模。

## 文件

- `PRD_乾隆的玩具盒.md`：产品需求与小红书容器约束。
- `index.html`：唯一入口文件。
- `styles.css`：柜体、开场、卡片与移动端视觉。
- `app.js`：主题随机、换物、长按重排、纪念卡等逻辑。
- `assets/`：全部本地图片资源。
